这个项目现在的核心竞争力是"公域内容获客闭环"——从多平台账号矩阵、AI 内容生产、多级审核、风控执行到评论收件箱，骨架已经很完整。但要真正在市场上拉开差距，我认为缺的是**输入端的"热点雷达"**和**输出端的"私域承接 + 转化归因"**这两端——现在的链路到"评论/私信/邮件发出"就断了，客户无法回答"这些互动到底带来了多少成交、哪条内容带来了客户"。

下面从四个引擎的角度给出建议，都尽量映射到你现有的代码结构上。

## 一、热点选题引擎（直接回应"热点话题抓取"）

这是投入产出比最高的一块，因为现有 `TopicLibrary`、`ai_generate_topics`、`content_strategy` 已经能承接选题生成，缺的只是"热点数据源 + 评分排序"。

**数据源分层接入：**
- 免费公开榜：微博热搜、知乎热榜、百度热搜、抖音热榜、B站热门——用现有 Playwright 浏览器引擎抓取即可，工作量主要在解析
- 指数类：百度指数、微信指数（部分需登录，可做半自动）
- 付费商业数据：新榜、蝉妈妈、灰豚数据、千瓜、5118——用它们的内容榜单和关键词数据，准确度高且合规

**核心功能：**
- 新增 `services/hot_topic_service.py`：定时抓取各平台热榜 → 归一化成统一模型 → 入库 `TopicLibrary`（加 `source/hot_score/trend` 字段）
- **热度评分模型**：热度绝对值 × 增长斜率（判断是"正在爆发"还是"已过峰"）× 与用户产品/行业关键词的相关度 × 获客潜力分（这类话题下用户会不会问"多少钱/怎么买"——可以直接复用 `notification_service` 里的购买意图关键词库）
- **时效衰减**：给每个热点算半衰期，分数随时间衰减，避免推荐过气话题
- **自动建选题**：评分过阈值的直接生成选题草稿（复用现有 AI 生成链路），审核后进入内容生产
- **热点日历**：预置节假日/行业节点（双 11、行业展会、新品发布季），提前 1-2 周生成内容储备，这是"可预期流量"的稳定来源
- **快反模式**：热点出现后 1 小时内产出 3 个平台版本并提交审核，看板新增"热点响应时长"指标——蹭热点的核心是速度

## 二、私域承接与转化闭环（回应"运营闭环"）

现在是"公域互动后没有下一步"。要做成真正的获客平台，必须打通"公域 → 私域 → 成交"：

- **私域承接**：评论/私信自动引导话术已经有了（`content_strategy.generate_reply`），补上落地动作——企业微信「客户联系」API 对接：活码管理、加好友后自动欢迎语、自动打标签（来源平台/话题/意向等级）、推送资料包或优惠
- **线索旅程状态机**：`Lead` 已有 `sla_deadline`、`contact_count` 字段，扩展成完整阶段：接触 → 意向确认 → 报价 → 成交 → 流失 → 复购，每个阶段配 SLA 和"下一步动作"
- **跟进节奏引擎**：复用 `scheduler` 做第 1/3/7 天的自动跟进队列，AI 基于上一轮回复生成差异化跟进话术（"客户没回 → 换个钩子；回了但犹豫 → 发案例/报价"）
- **转化归因**：这是目前最缺的闭环数据。每次触达记录来源（`task_id`/`content_id`/渠道），成交时反查归因——"知乎哪篇回答、哪条评论带来了客户"，`ContentPerformance.leads_generated` 字段已经在，把它做成真正的归因链路即可
- **流失原因反哺**：未成交时收集原因（价格/不需要/竞品），沉淀成数据反哺内容策略——哪些钩子无效，下次不写

## 三、流量与内容优化引擎（回应"更容易获得流量"）

流量不是玄学，是可拆解的特征。现有 `ContentPerformance` 数据已经积累了素材，缺的是分析和复用：

- **爆款拆解**：对高流量作品做特征分析——标题句式、标签组合、发布时间、内容长度、开头写法，生成"爆款配方"建议。现有"最佳发布时间分析"就是这个雏形，扩展到标题/标签/结构维度
- **搜索流量布局**：知乎和小红书是中文互联网最强的搜索获客渠道。接入下拉词/长尾词工具，生成内容时注入搜索词（`generate_post` 已有 SEO 关键词参数，增强成自动选词）
- **内容 A/B 测试**：同一内容生成 3 个标题/开头变体（`generate_variants` 已有），分发到多个账号，统计胜出版本沉淀进素材库
- **互动率优化**：平台推荐加权看互动率。在自己内容下用提问式结尾引导评论，AI 自动回复（已有 `auto_reply`）把回复率拉到 48 小时内 90% 以上，这是免费的流量杠杆
- **一鱼多吃流水线**：知乎回答 → 小红书图文 → 微博短帖 → 公众号文章，跨平台再创作，每个版本独立适配 + 过原创检测（`originality-check` 已有），一套选题吃透全网
- **AI 配图/封面**：接入图像生成能力做封面，小红书/视频封面点击率对流量影响极大

## 四、竞争情报与增长洞察

- **竞品账号监控**：监控同行业头部账号（复用平台账号体系 + 定时抓取），追踪他们的内容、互动、涨粉趋势
- **内容差距分析**：找出"竞品高互动、但你们没覆盖"的话题，直接生成可借势的选题
- **周报机器人**：每周自动生成《获客表现 + 竞品动态 + 本周热点机会》摘要，推送到飞书/钉钉/微信——让老板每周看到平台价值
- **渠道 ROI 对比**：每个渠道的获客成本、线索质量（AI 评分均值）、转化率横向对比，指导预算投向

## 产品差异化：卖"闭环"而不是卖"工具"

市面上的竞品大多是单点工具——文案生成器只会写，评论机器人只会发，舆情工具只会看。你的差异化叙事应该是：

> **从热点到成交的全自动获客闭环**：热点雷达自动选题 → AI 多平台内容生产 → 多级审核 → 风控执行 → 私域承接 → 转化归因 → 数据反哺内容。

这个叙事同时解决三个客户真实痛点：**不知道发什么**（热点引擎）、**发了没效果**（流量优化+归因）、**有互动没成交**（私域承接）。

配套工程化动作：把执行流程可视化（任务队列、执行状态），支持飞书/企微通知；长期可 SaaS 化（多租户、套餐计费），短期先以内置功能交付。

## 落地路线图

| 阶段 | 内容 | 价值 | 工作量 |
|---|---|---|---|
| 第一期（1-2 周） | 热榜抓取 + 评分 + 自动选题，跟进队列 | 直接解决"发什么"，见效最快 | 中（复用 Playwright 和 TopicLibrary） |
| 第二期（1 个月） | 企微私域承接、转化归因、爆款拆解、竞品监控 | 打通成交闭环，可讲完整故事 | 大（企微 API + 数据模型） |
| 第三期（2-3 个月） | 工作流编排、多租户 SaaS、生态集成（飞书/CRM） | 商业化 | 大 |

一个务实的提醒：私域加粉、爬虫抓取、批量评论都有平台风控和合规边界，建议优先走官方开放能力（企业微信 API、抖音/小红书开放平台），爬虫类功能严格控制频率并做账号健康管理——这本身就是你们风险控制模块的差异化卖点，包装成"安全获客"反而更值钱。
